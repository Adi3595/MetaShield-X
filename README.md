## ⚡ Overview

Traditional firewalls rely on rigid rules and massive SQL databases to catch threats. The problem? **They can't catch what they've never seen before.**

**MetaShield-X** throws out the database and replaces it with pure mathematics. Built with an Avant-Garde Next.js frontend and a stateless Python AI backend, MetaShield-X actively ingests live network telemetry and uses **Bayesian Few-Shot Inference** and **Shannon Entropy calculations** to map and isolate cyber attacks in real-time. 

If a hacker tries a Zero-Day attack that has never existed before, the AI's entropy threshold mathematically isolates the chaos and shuts it down anyway.

## 🔥 Key Features

- 🦠 **Zero-Day Catching:** Uses Shannon Entropy boundaries to detect completely unknown anomalies mathematically.
- 🧪 **Live Few-Shot Adaptation Lab:** A cinematic UI that allows engineers to generate and inject new attack prototypes on the fly without retraining a neural network.
- 📉 **Dynamic Concept Drift:** The system actively monitors its own "Drift Level." If hackers change tactics, the system tracks the mathematical decay so engineers can recalibrate instantly.
- 🎯 **Live Attack Injector Terminal:** A built-in terminal (at `/injector`) allowing you to simulate and fire raw payloads across your local network directly into the AI engine to prove real-time responsiveness.

## 🛠️ Getting Started

### 1. Boot the AI Inference Backend
Navigate to the backend and start the Python intelligence engine:
```bash
cd backend
python server.py
```
*(Runs on `http://localhost:8000`)*

### 2. Boot the Command Center Frontend
Navigate to the frontend and start the Next.js server:
```bash
cd frontend
npm run dev
```
*(Runs on `http://localhost:3000` or `3002`)*
