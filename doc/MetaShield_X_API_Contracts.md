# MetaShield-X: API Contracts & Networking

This document outlines the exact network protocols and JSON structures used to transmit data between the Next.js Frontend Command Center and the FastAPI Backend Intelligence Engine.

## 1. The Core Endpoint

### `POST /api/v1/events`
This is the primary ingestion endpoint. The frontend continuously sends telemetry logs to this URL, and the backend responds synchronously with a threat classification.

**URL**: `http://localhost:8000/api/v1/events`
**Method**: `POST`
**Content-Type**: `application/json`

---

## 2. The Request Payload (Frontend &rarr; Backend)

When the dashboard detects (or simulates) network traffic, it constructs a JSON payload containing the raw features of the event.

**Example Request:**
```json
{
  "timestamp": "2026-09-23T13:45:00.000Z",
  "source_ip": "10.0.145.22",
  "destination_ip": "10.0.1.4",
  "protocol": "TCP"
}
```

### Data Dictionary:
- `timestamp` (String/ISO): The exact time the packet was intercepted.
- `source_ip` (String): The IPv4 address of the originating machine.
- `destination_ip` (String): The IPv4 address of the target machine inside the network.
- `protocol` (String): The transport layer protocol (e.g., TCP, UDP, ICMP).

---

## 3. The Response Payload (Backend &rarr; Frontend)

Once the FastAPI server ingests the request, it passes it through the Entropy, Bayesian, and Drift modules. It then constructs a comprehensive response detailing exactly how the AI classified the event.

**Example Response (201 Created):**
```json
{
  "id": "a9b8c7d6e",
  "source_ip": "10.0.145.22",
  "destination_ip": "10.0.1.4",
  "predicted_class": "DoS / Slowloris",
  "status": "KNOWN_THREAT",
  "risk_score": "CRITICAL",
  "confidence": 0.94
}
```

### Data Dictionary:
- `id` (String): A unique identifier generated by the backend for tracking the event.
- `predicted_class` (String): The specific threat signature recognized by the Bayesian engine (e.g., "UNKNOWN BEHAVIOR" if flagged by the Novelty Detector).
- `status` (String): The internal engine status (e.g., `NORMAL`, `KNOWN_THREAT`, `NOVELTY`).
- `risk_score` (Enum): The severity of the event. Valid values are `LOW`, `MEDIUM`, `HIGH`, `CRITICAL`. This directly maps to the frontend CSS status badges (Chartreuse, Red, White).
- `confidence` (Float): A value between 0.0 and 1.0 representing the Bayesian probability certainty of the classification. This is multiplied by 100 on the frontend to display a percentage.
